# MUSIC & ART — два мира творчества

Сайт творческой мастерской «Рыбка» и музыкальной студии stARTup в Лазаревском.

## Технологии
React, TypeScript, Vite, Canvas, Web Audio API, jsPDF, lamejs, GitHub Pages.

## Запуск
```bash
npm install
npm run dev
npm run build
```

## Публикация
Откройте Settings → Pages → Build and deployment → Source: **GitHub Actions**. Каждый push в main запускает автоматическую сборку и публикацию.

## Страницы
- `/` — интерактивный выбор двух миров
- `/art` — творческая мастерская
- `/art/draw` — рисование, штампы, раскраски, экспорт PNG и PDF
- `/music` — музыкальная студия
- `/music/studio` — секвенсор с темпом, пресетами, громкостью и экспортом WAV/MP3

## Контакты и контент
Данные находятся в `src/data.ts`. Изображения пока загружаются с Pexels по внешним URL; для финального коммерческого релиза их необходимо заменить на согласованные фотографии студий, разместить локально и проверить условия лицензирования.

## Ограничения
Нет CMS, афиши, личных кабинетов, оплаты и серверного хранения детских рисунков. Все интерактивные инструменты работают в браузере. Для публикации необходимо включить GitHub Pages в настройках репозитория.

## Контроль качества
GitHub Actions содержит отдельный workflow Build verification, выполняющий `npm run build` и проверку выходных файлов.
