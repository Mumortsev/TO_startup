# MUSIC & ART — два мира творчества

Промосайт творческой мастерской **«Рыбка»** и музыкальной студии **stARTup** в Лазаревском.

## Разделы
- `/TO_startup/` — интерактивный выбор двух студий, адаптивный 50/50 экран, параллакс и GSAP-анимация.
- `/TO_startup/art` — «Рыбка»: направления, фотографии, полноэкранная галерея, контакты.
- `/TO_startup/art/draw` — локальная рисовалка: кисти, маркер, карандаш, ластик, штампы, шаблоны, история изменений, PNG/PDF A4.
- `/TO_startup/music` — stARTup: инструменты, галерея, кинематографический первый экран, локальные световые эффекты.
- `/TO_startup/music/studio` — четырёхдорожечный 16-шаговый Web Audio секвенсор, пресеты, BPM, громкость, экспорт WAV/MP3.
- Неизвестные адреса — 404 с возвратом на главную.

## Запуск
Требуется Node.js 20+.
```bash
npm install
npm run dev
npm run build
npm test
npm run test:e2e
```
Для E2E: `npx playwright install chromium`. Playwright запускает локальный Vite preview после сборки.

## Публикация
Workflow `.github/workflows/pages.yml` публикует `dist` при push в `main`.
В GitHub → Settings → Pages → Build and deployment установите **Source: GitHub Actions**. Публичный адрес при включённом Pages: https://mumortsev.github.io/TO_startup/

GitHub Pages поддерживает прямые ссылки на вложенные страницы через `public/404.html`. Vite base настроен на `/TO_startup/`.

## Техническая архитектура
React 18, TypeScript, Vite, GSAP, Canvas API, Web Audio API, jsPDF, lamejs, Vitest, Playwright.
Без бэкенда, регистрации, платежей, CMS и хранения детских рисунков на сервере. Рисунки и музыка создаются и экспортируются в браузере.
