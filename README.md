# Music & Art — два мира творчества

Сайт художественной мастерской **«Рыбка»** и музыкальной студии **stARTup** в Лазаревском.

[Открыть сайт](https://mumortsev.github.io/TO_startup/) · [GitHub Actions](https://github.com/Mumortsev/TO_startup/actions)

## Разделы

- `/TO_startup/` — выбор студии одним нажатием.
- `/TO_startup/art/` — художественная мастерская, направления, галерея, контакты.
- `/TO_startup/music/` — музыкальная студия, инструменты, интерактивная визуализация ритма.
- `/TO_startup/art/draw/` — 69 оригинальных иллюстраций, поиск и категории, заливка областей, палитра, отмена, очистка, масштабирование, сохранение на устройстве, PNG с атрибуцией.
- `/TO_startup/music/studio/` — простой детский секвенсор с жанрами, квадратиками, записями барабанов, гитары и баса и скачиванием WAV. Оболочка показывает загрузку, ошибку и повтор; доступно открытие отдельно и fullscreen.

## Разработка

Node.js 22.12+.

```bash
npm ci
npm run dev
npm test
npm run build:production
npx playwright install chromium firefox webkit
npm run test:e2e
```

`npm run build` проверяет TypeScript и собирает оболочку, раскраски и статические entry points. Музыкальный движок собирается отдельным шагом (`bash scripts/build-upstream-engines.sh`) из закреплённого upstream SHA. Для проверки всех приложений используйте `build:production`. При локальной разработке только оболочки музыкальное приложение не появится автоматически: сначала соберите его в `public/engines/music` командой `ENGINE_OUTPUT_DIR="$PWD/public/engines/music" bash scripts/build-upstream-engines.sh`; папка исключена из git.

Для браузерной валидации всех раскрасок запустите preview и в другом терминале:

```bash
COLORING_URL=http://127.0.0.1:4173/TO_startup/ npm run validate:coloring
```

Для Firefox/WebKit воспроизведение требует работающего системного аудиовыхода; в CI запускается настоящий PulseAudio null sink. Это не подмена Web Audio API. `WEBKIT_EXECUTABLE_PATH` позволяет указать локальный WebKit wrapper при нестандартном окружении.

`PLAYWRIGHT_BASE_URL` позволяет запускать E2E против опубликованного сайта. `PLAYWRIGHT_EXECUTABLE_PATH` — опциональный путь локального Chromium. Скриншоты, трассировки и отчёты не входят в исходный код; CI сохраняет браузерные результаты как артефакт.

## Архитектура и публикация

React 18, TypeScript, Vite 7, GSAP, Lucide, локальные Onest/Lora и WebP. Draw/Beat и их CSS загружаются отдельно. Раскраски и фотографии хранятся локально. Прогресс раскраски сохраняется компактно в IndexedDB; серверного хранения нет. NeonDAW интегрирован через same-origin iframe, его аудиодвижок и формат проектов сохранены.

Pages workflow запускается при push в `main`, вызывает reusable quality workflow: `npm ci`, unit, production build, pinned engine, Playwright, проверка ресурсов. Публикуется собранный артефакт. По явному запросу пользователя выпуск с `[no tests]` в сообщении коммита пропускает unit- и браузерные тесты; при ручной публикации это настраивается флагом `run_tests`. Сборка обязательна. Статические HTML-входы поддерживают прямые URL основных разделов; `404.html` восстанавливает остальные SPA-пути.

## Обновление интерфейса

Главная занимает один экран: равные половины сверху/снизу в портретной ориентации и слева/справа в альбомной. В раскрасках кнопка возврата закреплена; браузерное «Назад» возвращает к поиску и позиции в галерее. Форма записи пока не отправляет данные и сообщает об этом явно; контакт ВКонтакте находится внизу. Жанры секвенсора добавляют отдельный ритм, сохраняя старые; исходный движок, ключ localStorage и полный JSON проектов остаются прежними. Мелодии, эффекты и аранжировки старых проектов сохраняются и воспроизводятся.

## Детский секвенсор

В приложении один экран: шесть жанров (рок, поп, хип-хоп, фанк, хаус, регги), квадратики барабанов, гитары и баса, «Играть / Стоп», «Медленнее / Быстрее», длина 4/8/16 тактов, очистка и скачивание WAV. Импорт файлов, библиотека, микшер, выбор нот/аккордов, копирование и диапазоны убраны из интерфейса.

Каждое открытие начинается с пустых 4 тактов. Жанр меняет темп, тембр и гармонию гитарных клеток, сохраняя включённые клетки без автоматического заполнения. Одно нажатие добавляет звук, повторное убирает его. Гитарные аккорды и басовые ноты подбираются автоматически. При временном уменьшении длины скрытые такты сохраняются до закрытия приложения. Экспорт включает только выбранную длину и естественный хвост звука.

Текущий шаг приходит из `Tone.Draw` аудиодвижка. Текущая колонка подсвечивается, а включённые клетки в ней вспыхивают; страница сетки автоматически следует за воспроизведением. На узком экране показано по 8 шагов, на широком — по 16. Предыдущие проекты перед открытием пустого детского трека сохраняются в прежний ключ `startup:rock-project-library:v1`, без доступа к библиотеке из детского интерфейса. Если резервное хранение недоступно, прежний проект не заменяется.

Записи настоящих инструментов CC0 остаются локальными: [источники](public/rock-audio/README.md). Исходный аудиодвижок и его JSON-формат сохранены.

Карточки главной увеличиваются через compositor-слои, рыбка уплывает, пластинка уезжает с вращением. Картинка выбранного раздела подготавливается во время перехода. Поверх уже смонтированного раздела затухает лёгкий цветовой слой, чтобы убрать резкий стык. Рыбка перемещается через HTML-обёртку; её SVG не изменяется на каждом кадре. При системном предпочтении уменьшенных анимаций переход остаётся мгновенным.

По запросу пользователя выполняется production-сборка без unit- и браузерных тестов.

### Готовые мелодии

В постоянно видимом блоке «Готовые мелодии» доступны два авторских примера для каждого из шести жанров (12 всего). Примеры включают барабаны, гитару и бас, заполняют выбранную длину 4/8/16 тактов и редактируются обычным включением/выключением клеток. До загрузки предыдущий трек архивируется; кнопка «Вернуть прежний трек» восстанавливает его вместе с жанром, темпом и длиной. Пустой старт и отсутствие импорта сохранены.

Блок готовых мелодий всегда виден над сеткой. Адрес iframe музыкального приложения включает ревизию публикации, чтобы новая версия не заменялась закэшированным entry point предыдущей сборки.
