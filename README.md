# MUSIC & ART — Два мира творчества

React + TypeScript + Vite. Сайт мастерской «Рыбка» и музыкальной студии stARTup.

## Локальный запуск
```bash
npm install
npm run dev
npm run build
```
Публикация через GitHub Actions → GitHub Pages. В настройках Pages выберите Source: GitHub Actions.

## Разделы
Главная — выбор мира; /art — мастерская; /art/draw — рисовалка с PNG/PDF; /music — студия; /music/studio — секвенсор с WAV.

События, CMS, личные кабинеты и оплата не входят в версию 1.0. Контент — в src/data.ts.
