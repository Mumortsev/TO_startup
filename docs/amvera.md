# Размещение на Amvera Cloud

Домен: https://artmusiclazarevskoe.ru. Репозиторий проекта: https://git.msk1.amvera.ru/anutochka13/art-music.

## Исходная версия

В корне находятся Dockerfile, .dockerignore и amvera.yml. Docker собирает сайт и закреплённую версию NeonDAW в Node.js 22, затем передаёт только готовые публичные файлы в Nginx на порту 80. Во время работы Node.js не требуется. Оригиналы фотографий, .git, .env, node_modules и временные результаты в контейнер не копируются.

Сборка Amvera явно задаёт SITE_BASE_PATH=/ и SITE_URL/VITE_SITE_URL=https://artmusiclazarevskoe.ru. Переделаны пути к раскраскам, iframe секвенсора, локальным звукам, фотографиям, favicon и странице лицензий. Содержимое, аудиодвижок и форматы проектов сохранены. Canonical, Open Graph, robots.txt и sitemap.xml генерируются под выбранный домен.

Обычный npm run build без этих переменных по-прежнему готовит GitHub Pages под /TO_startup/. GitHub-версия может работать параллельно до завершения переезда. В Nginx настроены прямые входы на /art/, /music/, /art/draw/, /music/studio/, резервный маршрут SPA и перенос старого префикса /TO_startup/ в корень.

Команда полной сборки для Amvera:

```sh
SITE_BASE_PATH=/ SITE_URL=https://artmusiclazarevskoe.ru VITE_SITE_URL=https://artmusiclazarevskoe.ru npm run build:production
```

## Загрузка

Git Amvera требует авторизацию аккаунта; одна ссылка на репозиторий её не предоставляет. Пароли и токены в код или архив не добавляются. Если доступ Amvera настроен локально, можно подключить дополнительный remote и отправить подготовленную ветку:

```sh
git remote add amvera https://git.msk1.amvera.ru/anutochka13/art-music
git push amvera HEAD:master
```

По документации Amvera для запуска используется ветка master. Перед отправкой нужно получить её текущее состояние и сохранить существующее содержимое проекта, если оно есть; force push не использовать. Другой вариант — загрузить готовый архив через интерфейс проекта, раздел «Репозиторий» / «Код». Исходная история GitHub не удаляется.

Для готового архива используется deploy/Dockerfile.prebuilt: только Nginx и каталог site с уже собранным сайтом. В корне загружаемого кода должны лежать Dockerfile, amvera.yml, nginx.conf и site/ — без дополнительной внешней папки. Такая сборка не скачивает npm-зависимости и не пересобирает аудиодвижок на сервере. Артефакт создан из полной производственной сборки, включая лицензии.

## Домен и HTTPS

1. В Amvera открыть art-music → «Домены» → добавить свой домен artmusiclazarevskoe.ru (HTTP/HTTPS, порт приложения 80).
2. В Reg.ru оставить NS ns1.reg.ru/ns2.reg.ru. У @ должна быть A-запись со значением из Amvera; не подставлять адрес по предположению.
3. Для этого проекта Amvera указала: A @ → 185.147.26.234 и TXT _amvera → anutochka13-art-music. Заменить прежнюю A @ → 95.163.244.138 и добавить TXT без кавычек в интерфейсе Reg.ru. Публичный DNS при последнем обращении ещё показывал прежнюю A-запись, а TXT отсутствовала; AAAA не обнаружена. Если записи уже изменены, нужно дождаться распространения DNS.
4. Для www добавить отдельный домен www.artmusiclazarevskoe.ru в Amvera и использовать выданные CNAME и TXT _amvera.www. Согласно актуальной документации для поддомена применяется CNAME; существующую A-запись www заменять только после получения целевого значения. Посторонние MX/TXT-записи не удалять.
5. После распространения записей завершить привязку и дождаться выпуска сертификатов в Amvera. SSL обслуживает платформа, Nginx внутри контейнера слушает HTTP 80. Для www предусмотрен переход на основной HTTPS-домен.

Технический адрес проекта нужно взять из вкладки «Домены» Amvera; по имени Git-репозитория он не определяется надёжно.

Инструкции: https://docs.amvera.ru/applications/configuration/docker.html и https://docs.amvera.ru/applications/configuration/network.html .

## Сохранения браузера

Локальные раскраски и музыкальные проекты привязаны к origin. Они остаются в браузерном хранилище прежнего GitHub-адреса и не появляются автоматически на новом домене. Для переноса пользовательских работ нужны штатные экспорт/сохранение из прежней версии; форматы и совместимость аудиодвижка не менялись. GitHub-адрес не отключается при подготовке.

Тесты и браузерные проверки по просьбе пользователя не запускались. Выполнена полная сборка для корня нового домена; Docker-контейнер локально не запускался. Публикация на Amvera пока требует авторизованной загрузки в аккаунт владельца.
