# Аудит и концепция

Исходная версия: 497a2e310889a23e72d59ca49df4e2a2e748d9a4.

Недочёты: двухшаговый выбор мира и вложенная псевдокнопка; тёмные однотипные split-screen фотографии без выразительной идентичности; глобальная загрузка Draw/Beat; каскад конфликтующих CSS-патчей; неподтверждённые функции в README; зависимость галереи от отдельного CI скачивания; opacity вместо контролируемого контраста; отсутствие focus trap галереи; старые SVG-заглушки; динамические upstream HEAD и отсутствие lockfile.

Концепция: два листа одного творческого альбома. Общие Onest Variable и контентная сетка. Цвета: бумага #fffaf1, тушь #212b29, коралл #d54b35, мёд #f6ce72, мята #cbe5d3, музыкальная синева #253d69. Рыбка сочетает крупное имя с иллюстрацией рыбы и фотографией художественного процесса; stARTup использует крупное слово и волнообразную типографику на светло-голубом поле с локальным тёмным плеером. Главная ведёт в каждый мир одним нажатием.

Решение после сверки с заданием: избегаем общей кремово-терракотовой темы для обеих студий. Музыкальный мир получает собственную синюю систему, а карточки направлений — структуру списка с изображением вместо одинаковых маркетинговых плиток. Смысловые иллюстрации и живые инструменты задают характер, декоративный WebGL не нужен.

Скиллы прочитаны и применяются вручную, без установки их starter и framework: Anthropic frontend-design ca45fc496a3436251f191354091d557da31c15b5; Taste Skill 2.5.0 9b4bf937a1f69348126959c15d2f99a73e65699b (в текущей версии нет отдельных high-end-visual-design/redesign-existing-projects); Better Web UI af21dcfa71d83104a9e0beb04ffedf79f800f53c (maintenance mode). Из Taste берём равные края, реальный визуальный материал и спокойные взаимодействия. Его требования подменить контакты на .example, запретить заданные анимации и целиком заменить проект стартером противоречат заданию, поэтому не применяются.

UI-источники проверены: React Bits SplitText использует GSAP + @gsap/react + ScrollTrigger; Magic UI BlurFade использует motion/react; Aceternity демонстрирует image-wave, карточки и переходы; motion-primitives-website содержит animated-layout и svg-компоненты на Framer Motion/Next. Код этих библиотек не переносился: для данной React/Vite оболочки те же принципы реализованы существующим GSAP и CSS, без дублирующего motion runtime. React Bits лицензия MIT + Commons Clause, Magic UI MIT; в указанном motion-primitives-website отсутствует LICENSE, поэтому копирование его кода исключено. Aceternity бесплатные и Pro компоненты имеют разные условия: платный код не использован.
