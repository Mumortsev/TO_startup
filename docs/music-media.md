# Материалы музыкальной студии

Тексты и контакты заказчика находятся в `src/musicContent.ts`, новая страница — в отдельном лениво загружаемом модуле `src/MusicStudio.tsx`. Гитара, бас-гитара, барабаны, индивидуальные и групповые занятия, возможность создать группу, концерты, взрослые и дети с 7 лет — по присланным материалам. Телефон +7 (961) 506-27-73 и адрес Социалистическая, 1 относятся только к музыке. Данные мастерской «Рыбка» сохранены отдельно. Запись доступна через личный чат в MAX (ссылка в `musicContact.max`) и телефон. Форма-заглушка удалена. Основная кнопка «Написать в MAX» открывает личный чат, контурная кнопка — звонок. На экранах шире 760 px показан компактный SVG QR-код на тот же адрес; на телефоне остаются только кнопки. QR-код сгенерирован локально из точной ссылки с помощью `qrcode@1.5.4`, без внешних сервисов и зависимостей клиентского приложения. Изображение лениво загружается, зелёный фон исходного скриншота не используется.

Все семь оригиналов скачаны из предоставленной папки Google Drive и хранятся в игнорируемой `private-media/music/`. Соответствие файлов блокам — `media/music-photos.json`: 12308 — занятие детей с барабанами; 26264 — гитары и бас; 26266 — барабаны; 26268 — акустическая гитара; 26270 — барабаны крупным планом; 46284 — портрет (первый экран); 55378 — игра на барабанах. По фотографиям не придумываются имена и биографии. Портрет остаётся на первом экране; гитара, гитары/бас и барабаны — у направлений; игра на барабанах — в блоке о сцене. Прежняя галерея из двух снимков заменена отдельным альбомом учеников. Повторного использования фотографий в разных блоках нет.

```sh
node scripts/prepare-site-photos.mjs
```

Команда готовит фотографии музыки и «Рыбки» из оригиналов. Требуется ImageMagick 7. Создаются до четырёх WebP по ширине (320/640/960/1280 px) с ограничением высоты 1600 px, без увеличения оригинала и без обрезки. Дубликаты размеров для небольших исходников не создаются. Качество — 85, ICC сохраняется, EXIF/XMP/IPTC удаляются. Визуальное содержимое не ретушируется, композиция и цвета не корректируются. Метаданные версий автоматически записываются в `src/sitePhotos.generated.json`.

Публичные страницы используют ResponsivePhoto: браузер выбирает фактическую ширину из srcset/sizes. Только первый экран получает eager/high; остальные снимки — lazy/async. В галерее указаны размеры ячеек, а в увеличенном просмотре — размер экрана. Картины в витрине используют отдельный скрипт `scripts/prepare-artworks.mjs`: четыре размера и водяной знак, высокое разрешение загружается при открытии картины. Оригиналы не публикуются.

Маршрут секвенсора, его аудиодвижок, готовые мелодии, сохранение старых проектов и экспорт не изменены. Тесты и браузерные проверки по просьбе пользователя не запускаются. Для публикации — обычная сборка; сообщение коммита с `[no tests]` пропускает тестовые этапы GitHub Actions.

## Альбом «Ученики студии»

Семь новых оригиналов: 111544, 111552, 111559, 132609, 132616, 132620, 132634. Хранятся в игнорируемой `private-media/music-album/`; соответствие — `media/music-album-photos.json`. Обложка — горизонтальное фото 111552 с бас-гитаристкой. Альбом занимает прежний блок фотографий, на десктопе обложка слева и подпись справа, на телефоне подпись под обложкой. Основной портрет и карточки инструментов сохранены.

Подготовка: `node scripts/prepare-site-photos.mjs music-album`. Тот же профиль WebP: качество 85, до четырёх размеров, без увеличения, с сохранением ICC и удалением личных метаданных. На странице выводится одна обложка; фотографии остальных снимков появляются только при открытии просмотрщика.

Все альбомы обоих разделов и увеличенный просмотр картин используют `PhotoCarousel` и общий `useLoopingCarousel`. Нативная горизонтальная прокрутка и scroll-snap дают плавный свайп без JavaScript-анимации каждого кадра; кнопки и клавиатура используют smooth scroll с учётом prefers-reduced-motion. Крайние копии позволяют пройти последнюю → первую и первую → последнюю за один слайд. Счётчик учитывает только реальные фотографии. В DOM загружаются текущий и соседние снимки, а не весь альбом. Просмотрщик корректно ждёт открытия dialog перед расчётом ширины; после закрытия очищает обработчики и возвращает фокус обложке.
