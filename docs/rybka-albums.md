# Альбомы мастер-классов

Добавлены два альбома из предоставленных заказчиком папок Google Drive: «Мастер-класс на выезде» — 12 файлов; «Мастер-класс в мастерской» — 10 файлов. Количество соответствует фактическому содержимому папок, а не предварительному предположению 10/8.

Оригиналы сохранены в игнорируемой `private-media/rybka-albums/outdoors/` и `workshop/`. Пять файлов с расширением `.dng` фактически содержали JPEG. Рядом сохранены побайтовые копии с правильным расширением `.jpg`; преобразование RAW и цветокоррекция не применялись. Соответствие снимков идентификаторам — `media/rybka-albums-photos.json`.

Для повторной подготовки только этих снимков:

```sh
node scripts/prepare-site-photos.mjs rybka-albums
```

Команда без аргументов теперь готовит все четыре группы фотографий. Метаданные других групп сохраняются при выборочной обработке. WebP: до 320/640/960/1280 пикселей по ширине, ограничение высоты 1600, качество 85, без увеличения небольших оригиналов, с сохранением ICC и удалением EXIF/XMP/IPTC. Изображения не обрезаются и не ретушируются. Публично размещаются только облегчённые версии; исходники не публикуются.

`src/workshopAlbums.ts` задаёт названия и обложки, состав и счётчики автоматически берутся из манифеста. Обложки: 55270 (стол для выездного занятия у озера) и IMG_3967 (подготовленная мастерская). Обе фотографии одного формата, поэтому карточки выстраиваются ровно без полей и обрезки. Раздел расположен после описания мастер-классов, перед форматами встреч. Существующая галерея мастерской сохранена.

PhotoGallery получает необязательный флаг `album`: на странице выводит одну обложку, название, число фото и действие «Смотреть альбом». Остальные снимки не вставляются в DOM до открытия. Увеличенный просмотр плавно листает фотографии нативной циклической каруселью; загружает текущую фотографию и соседние и использует responsive srcset/sizes, стрелки, циклическую навигацию, свайпы, Escape, блокировку прокрутки и возврат фокуса к обложке. Обычные галереи музыки и мастерской работают в прежнем режиме.
