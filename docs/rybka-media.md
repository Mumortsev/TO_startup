# Материалы мастерской «Рыбка»

Страница использует тексты заказчика из `src/artContent.ts`. Главная, музыкальная студия, секвенсор и раскраски сохраняют свои маршруты. Новая страница мастерской загружается отдельным модулем.

## Фотографии

Изображения видны в переписке, но их файлы не были предоставлены исполнителю. До получения исходников `src/artPhotos.generated.json` остаётся пустым; публикация финальной страницы ожидает фотографии. Стоковые снимки не подставляются вместо фотографий заказчика.

После получения архива разместить его содержимое в `private-media/` (игнорируется Git), сопоставить имена с `media/rybka-photos.example.json` и выполнить:

```
node scripts/prepare-art-media.mjs photos /absolute/private-media/rybka-photos.json
```

Нужен ImageMagick 7 (`magick`). Генерируются WebP 640/1200 px без увеличения небольших снимков и без EXIF; естественные пропорции и ориентация сохраняются. Зависимости клиентского приложения не добавляются. Метаданные размеров записываются в `src/artPhotos.generated.json` после обработки всех девяти файлов.

Распределение: 01 — Анна рисует зайца (об Анне); 02 — занятие с детьми (первый экран); 03 — Анна у доски; 04 — процесс крупным планом; 05 — кисти/палитра (о мастерской); 06 — стол с угощениями (форматы встреч); 07 — деревянный домик; 08 — цветы на столах; 09 — общий вид помещения. Снимки 03/04/07/08/09 составляют галерею.

## Будущая витрина картин

Сейчас витрина содержит вводный текст и обращение к Анне. Утверждённых фотографий отдельных доступных к приобретению работ и их характеристик пока нет. Общие снимки мастерской не выдаются за продаваемые картины.

Для каждой будущей картины:

```
node scripts/prepare-art-media.mjs artwork /absolute/private-media/original.jpg painting-slug
```

Скрипт запекает повторяющийся полупрозрачный знак «Мастерская „Рыбка“» и подпись © в обе публичные версии. Знак содержится в пикселях, включая изображение для увеличенного просмотра; CSS-наложение не используется. Оригиналы запрещено передавать из `public/` и нельзя публиковать вместе с витриной. Результат команды содержит пути и размеры для новой записи `artworks` в `src/artContent.ts`. Тип `Artwork` допускает для витрины только пути с суффиксами `-marked-640.webp` / `-marked-1200.webp`.

Название, материал, размер, цена и доступность — только по данным Анны. Нажатие открывает подготовленную фотографию, «Узнать о работе» переводит к контактам с названием выбранной картины. Корзины, оплаты и загрузки собственных файлов в интерфейсе нет.
