# Материалы мастерской «Рыбка»

Страница использует тексты заказчика из `src/artContent.ts`. Главная, музыкальная студия, секвенсор и раскраски сохраняют свои маршруты. Новая страница мастерской загружается отдельным модулем.

## Фотографии

Все 9 фотографий получены 10 ноября 2026 года в архиве `rybka.zip`. Исходники находятся в игнорируемой папке `private-media/rybka/`. В сайт включены только облегчённые производные WebP; соответствие исходников блокам записано в `media/rybka-photos.json`. Стоковые снимки в новой странице мастерской не используются.

Для повторной подготовки разместить исходники в `private-media/rybka/` (игнорируется Git) и выполнить:

```
node scripts/prepare-art-media.mjs photos media/rybka-photos.json
```

Нужен ImageMagick 7 (`magick`). Генерируются WebP 640/1200 px без увеличения небольших снимков и без EXIF; естественные пропорции и ориентация сохраняются. Зависимости клиентского приложения не добавляются. Метаданные размеров записываются в `src/artPhotos.generated.json` после обработки всех девяти файлов.

Распределение: IMG_7296 — Анна рисует зайца (об Анне); IMG_7295 — занятие с детьми (первый экран); IMG_7300 — Анна у доски; IMG_7301 — процесс крупным планом; IMG_7302 — кисти/палитра (о мастерской); IMG_7303 — стол с угощениями (форматы встреч); IMG_7304 — деревянный домик; IMG_7305 — цветы на столах; IMG_7306 — общий вид помещения. Снимки IMG_7300/7301/7304/7305/7306 составляют галерею.

## Витрина картин

Подготовлен каталог из 20 работ в порядке получения: `media/rybka-artworks.json`. Номер стабилен и не зависит от положения слайда. Поля `title` (название), `size` (размер в сантиметрах, например «30 × 40 см») и `description` пока пустые: данные предоставит Анна. Не придумывать авторские названия или размеры. До получения названия показывается «Работа №NN»; пустые размер и описание не выводятся.

Все 20 оригиналов получены из четырёх архивов в предоставленной заказчиком папке Google Drive. Исходники сохранены в игнорируемой `private-media/artworks/drive/batch-1/` … `batch-4/`. Порядок соответствует четырём партиям в переписке, а не алфавитной сортировке файлов. Разметка углов каждого полотна и соответствие файлов номерам сохранены в `media/rybka-artworks-sources.json`.

`src/ArtworkCarousel.tsx`: нативная прокрутка со свайпами и фиксацией слайда, кнопки влево/вправо, клавиши стрелок, счётчик и увеличенный просмотр. Автоматического перелистывания нет. На широком экране изображение слева, сведения справа; на телефоне сведения под изображением. Всё полотно видно целиком; светлое паспарту и тонкая деревянная рамка добавлены средствами CSS с пояснением, что это пример оформления. «Узнать о работе» переводит к контактам с названием или номером.

### Подготовка исходников

Оригиналы хранить в игнорируемой `private-media/artworks/`. В Git находятся только относительные пути к исходникам и нормированные координаты углов. Пример записи частного манифеста:

```json
[
  {
    "id": "work-20",
    "file": "IMG_7782.HEIC",
    "corners": [[0.0286, 0.0453], [0.9714, 0.035], [0.9843, 0.9671], [0.0143, 0.9506]]
  }
]
```

Координаты нормированы от 0 до 1 на ориентированном исходнике. Порядок: верхний левый, верхний правый, нижний правый, нижний левый угол холста. Для каждой картины углы размечаются отдельно. Сохранять весь холст, включая любые существующие детали и знаки.

```sh
node scripts/prepare-artworks.mjs media/rybka-artworks-sources.json
```

Нужен ImageMagick 7 с поддержкой HEIC. Применяется только геометрическое выравнивание четырёх углов: фон снаружи холста убирается, живописное изображение не ретушируется, не дорисовывается и не подвергается цветокоррекции. Пропорции оцениваются по сторонам холста на фотографии; физические размеры не выводятся из пикселей. Создаются WebP до 960 и 2000 пикселей по длинной стороне, без увеличения исходников, с качеством 90 и удалением EXIF/XMP/IPTC. Исходный цветовой профиль ICC (в том числе Display P3 со смартфона) сохраняется в WebP, чтобы цвета корректно отображались в браузере. В обе версии запекается согласованный полупрозрачный знак «Мастерская „Рыбка“». Никакой новой подписи автора не добавляется. Оригиналы не попадают в `public/` или Git.

Размеры готовых изображений автоматически записываются в `src/artworks.generated.json`. В карусель попадают только записи с обработанными файлами. Дополняя манифест следующими работами, можно сохранить уже подготовленные изображения. Названия, размеры и описания можно дополнить позднее без повторной обработки изображений. Для публикации выполнить обычную сборку; по просьбе пользователя тесты и браузерные проверки не запускать. Онлайн-оплаты и корзины нет.
